`@smaranai/adapter-google` produces Gemini function declarations and a `systemInstruction` with recalled memories. First npm release pending — see the note on the [Anthropic page](/docs/adapters/anthropic).

## Inject recalled memories

```ts
import { GoogleGenAI } from "@google/genai"
import { Smaran } from "@smaranai/sdk-ts"
import { withRecalledContext, memoryTools } from "@smaranai/adapter-google"

const smaran = new Smaran({ apiKey: process.env.SMARAN_API_KEY!, baseUrl: process.env.SMARAN_URL })
const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY })

const { systemInstruction, contents } = await withRecalledContext(
  smaran,
  { systemInstruction: "You are a helpful assistant.", contents: history },
  { userId: "u_alice" },
)

const res = await ai.models.generateContent({
  model: "gemini-2.5-flash",
  contents,
  config: { systemInstruction, tools: memoryTools() },
})
```

## Handle function calls

```ts
import { handleFunctionCall, isMemoryFunctionCall } from "@smaranai/adapter-google"

const parts = await Promise.all(
  (res.functionCalls ?? [])
    .filter(isMemoryFunctionCall)
    .map((call) => handleFunctionCall(smaran, { name: call.name!, args: call.args ?? {} }, { userId: "u_alice" })),
)
// send parts back as a user turn: { role: "user", parts }
```

Each result is a `functionResponse` part. The Gemini Live API isn't covered by a dedicated helper; use the same functions with your Live session's tool calls.
