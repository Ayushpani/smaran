The Smaran skill is a single `SKILL.md` file that tells Claude Code how to call the Smaran API — save, recall, forget and voice ingest — when you ask it to add memory to an agent. It does not hook into Claude's own conversations or run anything on its own.

## Install

Copy the skill into your project:

```bash
mkdir -p .claude/skills/smaran
cp path/to/smaran/skills/smaran/SKILL.md .claude/skills/smaran/SKILL.md
```

Or into `~/.claude/skills/smaran/` to make it available in every project.

## Configure

Point the code Claude writes at your API:

```bash
export SMARAN_URL="http://localhost:8787"   # or your deployment
export SMARAN_API_KEY="sk_local_dev"         # sandbox key from `bun run try`
```

## What it covers

- `POST /v1/memories` — save facts, with self-correction and question filtering.
- `POST /v1/recall` — ranked recall, optional rerank and point-in-time `asOf`.
- `DELETE /v1/memories/:id` — forget.
- `POST /v1/ingest/partial` and `/commit` — streaming voice transcripts.
- The recommended pattern: recall before each reply, save concise facts after.
