`@smaranai/adapter-vapi` routes Vapi server-URL messages. Function calls to `memory_save` / `memory_recall` are executed and answered; user transcripts feed a `StreamingSession` that saves each final turn. A runnable template lives in `apps/starter-vapi`.

## Server handler

```ts
import { Smaran } from "@smaranai/sdk-ts"
import { StreamingSession } from "@repo/voice"
import { handleVapiEvent } from "@smaranai/adapter-vapi"

const smaran = new Smaran({ apiKey: process.env.SMARAN_API_KEY!, baseUrl: process.env.SMARAN_URL })

export async function POST(req: Request) {
  const { message } = await req.json()
  const callId = message.call?.id ?? "unknown"
  const userId = message.customer?.number ?? callId
  const session = new StreamingSession({ client: smaran, sessionId: callId, userId })

  const result = await handleVapiEvent(message, { memory: smaran, session, userId, sessionId: callId })
  return Response.json(result.response ?? {})
}
```

Keep one `StreamingSession` per call (for example in a `Map` keyed by call id) so partial transcripts accumulate across requests.

## Assistant configuration

Add the functions from `memoryFunctions()` to your assistant's tools and point its server URL at the handler above.
