`@smaranai/adapter-anthropic` translates Smaran into Anthropic Messages API shapes. It doesn't wrap the Anthropic client — you keep calling `messages.create` yourself.

```bash
npm i @smaranai/sdk-ts @smaranai/adapter-anthropic @anthropic-ai/sdk
```

<Callout tone="note" title="First npm release pending">
All `@smaranai/*` packages are built and smoke-tested for npm; until the first release, build them locally with `bun run scripts/build-package.ts packages/<name>`.
</Callout>

## Inject recalled memories

```ts
import Anthropic from "@anthropic-ai/sdk"
import { Smaran } from "@smaranai/sdk-ts"
import { withRecalledContext, memoryTools } from "@smaranai/adapter-anthropic"

const smaran = new Smaran({ apiKey: process.env.SMARAN_API_KEY!, baseUrl: process.env.SMARAN_URL })
const anthropic = new Anthropic()

const { system, messages } = await withRecalledContext(
  smaran,
  { system: "You are a helpful voice assistant.", messages: history },
  { userId: "u_alice", sessionId: "call_123", topK: 5 },
)

const res = await anthropic.messages.create({
  model: "claude-sonnet-4-5",
  max_tokens: 1024,
  system,
  messages,
  tools: memoryTools(),
})
```

`withRecalledContext` recalls against the last user message and appends a `<recalled-memories>` block to `system`. With no matching memories, `system` is unchanged.

## Handle tool calls

`memoryTools()` declares `memory_save` and `memory_recall`. Run the ones Claude calls and send the results back:

```ts
import { handleToolUse, isMemoryToolUse } from "@smaranai/adapter-anthropic"

const results = await Promise.all(
  res.content
    .filter(isMemoryToolUse)
    .map((block) => handleToolUse(smaran, block, { userId: "u_alice", sessionId: "call_123" })),
)
// next turn: messages.push({ role: "user", content: results })
```

Each result is a ready-made `tool_result` block.
