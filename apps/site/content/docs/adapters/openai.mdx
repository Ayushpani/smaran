`@smaranai/adapter-openai` works with the OpenAI Chat Completions format, which also covers OpenAI-compatible providers (Groq, Together, DeepSeek, Ollama, LM Studio, vLLM). First npm release pending — see the note on the [Anthropic page](/docs/adapters/anthropic).

## Inject recalled memories

```ts
import OpenAI from "openai"
import { Smaran } from "@smaranai/sdk-ts"
import { withRecalledContext, memoryTools } from "@smaranai/adapter-openai"

const smaran = new Smaran({ apiKey: process.env.SMARAN_API_KEY!, baseUrl: process.env.SMARAN_URL })
const openai = new OpenAI()

const messages = await withRecalledContext(smaran, history, { userId: "u_alice", topK: 5 })
const res = await openai.chat.completions.create({
  model: "gpt-4o-mini",
  messages,
  tools: memoryTools(),
})
```

`withRecalledContext` merges a `<recalled-memories>` block into the first system message (or adds one). With no matches, the messages are returned unchanged.

## Handle tool calls

```ts
import { handleToolCall, isMemoryToolCall } from "@smaranai/adapter-openai"

const calls = res.choices[0].message.tool_calls ?? []
const toolMessages = await Promise.all(
  calls.filter(isMemoryToolCall).map((c) => handleToolCall(smaran, c, { userId: "u_alice" })),
)
// append res.choices[0].message, then toolMessages, and call the model again
```

Python: `pip install smaran-openai-sdk` provides the equivalent for the OpenAI Python SDK once published; see `packages/openai-sdk-python`.
