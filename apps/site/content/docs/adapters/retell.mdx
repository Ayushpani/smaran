There's no dedicated Retell adapter yet. Retell agents reach your server through webhooks (custom LLM or custom functions), and the [TypeScript SDK](/docs/sdk) or [REST API](/docs/api) covers everything needed there.

## Custom function: recall

```ts
import { Smaran } from "@smaranai/sdk-ts"

const smaran = new Smaran({ apiKey: process.env.SMARAN_API_KEY!, baseUrl: process.env.SMARAN_URL })

export async function POST(req: Request) {
  const { call, args } = await req.json()
  const userId = call?.from_number ?? call?.call_id
  const { hits } = await smaran.recall({ userId, query: args.query, topK: 5 })
  return Response.json({ result: hits.map((h) => h.memory.text).join("\n") || "nothing found" })
}
```

## Saving turns

When your webhook receives the user's final utterance, save it (self-correction runs server-side):

```ts
await smaran.save({ userId, sessionId: call.call_id, text: userUtterance, source: "voice" })
```
