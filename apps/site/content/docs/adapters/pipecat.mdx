`smaran-pipecat` is a Pipecat `FrameProcessor`. Placed after the user context aggregator, it recalls memories for the latest user message, injects them into the LLM context, and saves the message.

## Install

```bash
pip install smaran-pipecat   # Python 3.11+
```

<Callout tone="warn" title="Publishing in progress">
`smaran-pipecat` depends on the core `smaran` package, which is being published to PyPI. Until it is, install both from the repo: `pip install ./packages/sdk-python ./packages/pipecat-sdk-python`.
</Callout>

## Pipeline

```py
import os
from pipecat.pipeline.pipeline import Pipeline
from smaran_pipecat import SmaranPipecatService

memory = SmaranPipecatService(
    api_key=os.getenv("SMARAN_API_KEY"),
    base_url=os.getenv("SMARAN_URL"),
    user_id="user-123",
    params=SmaranPipecatService.InputParams(search_limit=5, inject_mode="auto", save_memory=True),
)

pipeline = Pipeline([
    transport.input(),
    stt,
    context_aggregator.user(),
    memory,                       # recall + inject + save
    llm,
    tts,
    transport.output(),
    context_aggregator.assistant(),
])
```

`inject_mode` controls where memories go: `"system"`, `"user"`, or `"auto"`.
