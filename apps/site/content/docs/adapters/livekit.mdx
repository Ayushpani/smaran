There are two ways to use Smaran with LiveKit Agents.

## Python agents (most common)

`apps/voice-agent-livekit` is a complete, runnable LiveKit Agents (Python) voice agent. It recalls memories in `on_user_turn_completed` and injects them into the turn's context, and saves the user's turn — all over the REST API. Copy its `smaran_recall` / `smaran_save` helpers into your agent, or use the `smaran` Python SDK:

```py
from smaran import Smaran

smaran = Smaran(api_key=os.environ["SMARAN_API_KEY"], base_url=os.environ["SMARAN_URL"])

async def on_user_turn_completed(self, turn_ctx, new_message):
    text = new_message.text_content or ""
    hits = await smaran.recall(text, user_id=self.user_id, top_k=5)
    if hits:
        turn_ctx.add_message(
            role="system",
            content="Relevant facts you already know about this user:\n" + "\n".join(f"- {h.text}" for h in hits),
        )
    await smaran.save(text, user_id=self.user_id, session_id=self.session_id)
```

## Node agents

`@smaranai/adapter-livekit` (`npm i @smaranai/adapter-livekit`; first release pending) wraps a `StreamingSession`:

```ts
import { Smaran } from "@smaranai/sdk-ts"
import { LiveKitVoiceAdapter, memoryTools } from "@smaranai/adapter-livekit"

const smaran = new Smaran({ apiKey: process.env.SMARAN_API_KEY!, baseUrl: process.env.SMARAN_URL })
const adapter = new LiveKitVoiceAdapter({ memory: smaran, sessionId: roomName, userId })

adapter.onPartialTranscript(partialText)          // as ASR streams
adapter.onFinalTranscript(finalText)              // saves the turn (non-blocking)
const prefix = await adapter.buildContextPrefix(finalText) // "<recalled-memories>…" or ""
// For function calling: memoryTools() declarations + adapter.handleFunctionCall(call)
```
