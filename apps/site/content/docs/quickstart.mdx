The fastest way to try Smaran is the local sandbox: the full memory pipeline (cleaning, self-correction, semantic + keyword recall) running in one process with an in-memory store. It uses a free multilingual embedding model that runs on your CPU, so there are no API keys and no per-call costs.

## Prerequisites

Bun `1.4.4` or newer. Clone the repo and install once at the root:

```bash
git clone https://github.com/Ayushpani/smaran
cd smaran
bun install
```

<Callout tone="note" title="Why at the root?">
Smaran is a Bun workspace — the API imports the engine packages from `packages/`. Running `bun install` inside a nested app won't link them.
</Callout>

## Start the sandbox

```bash
bun run try
```

The first start downloads the embedding model (~120 MB, cached in `.smaran/models`), then prints the sandbox URL and key:

```
embedder: Xenova/multilingual-e5-small loaded in 1059ms
│ URL:     http://localhost:8787
│ Key:     sk_local_dev
```

## Save your first memory

```bash
curl -sX POST localhost:8787/v1/memories \
  -H "Authorization: Bearer sk_local_dev" \
  -H "Content-Type: application/json" \
  -d '{"userId":"u_alice","text":"confirm my order — one two three four, actually four three two one"}'
```

The stored memory (abridged):

```json
{
  "memories": [
    {
      "id": "mem_…",
      "text": "confirm my order — four three two one",
      "kind": "fact",
      "metadata": {
        "originalText": "confirm my order — one two three four, actually four three two one",
        "corrections": [
          { "kind": "patch", "retracted": "confirm my order — one two three four", "kept": "confirm my order — four three two one" }
        ]
      }
    }
  ]
}
```

The retraction cue (`actually`) was detected and the wrong value was replaced **before storage** — only the corrected form is ever recalled. What was dropped is kept in `metadata.corrections` for audit.

## Recall it

```bash
curl -sX POST localhost:8787/v1/recall \
  -H "Authorization: Bearer sk_local_dev" \
  -H "Content-Type: application/json" \
  -d '{"userId":"u_alice","query":"which order did the caller confirm","topK":3}'
```

Hits come back best first, each with the memory, a ranking `score` (for ordering only) and `latencyMs`.
